## 📌 Project Overview

An end-to-end enterprise banking analytics solution built on synthetic data 
covering loan analytics, customer churn, marketing ROI, employee productivity, 
and branch performance.

**Tech Stack:** Python | SQL Server | Power BI Desktop | Power BI Service | DAX | Power Query

## 🔑 Key Business Insights

- Unemployed borrowers driving **15.17%** default rate vs **8.80%** bank average
- Phone channel leads conversion at **35.7%** — outperforming all digital channels
- Mass Affluent segment showing highest churn at **2.10%**
- **10.16%** employee resignation rate flagged as HR retention risk
- Hartford CT Business loans flagged at **11.38%** default — highest in network
